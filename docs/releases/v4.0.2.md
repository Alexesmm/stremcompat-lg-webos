# StremCompat 4.0.2

## Fixed
- **Seeking in some large MKV files.** Files whose first index only points to a second one at the end, as some muxers write them, could not be seeked on the TV. When such a file plays through the app's proxy, the start of the file is corrected on the way so the player finds its seek table. Thanks to @Biditmangal ([#11](https://github.com/Alexesmm/stremcompat-lg-webos/pull/11)).
- **Samsung:** files and accounts that rely on decoding text, such as the Nuvio QR code, now work on the TV's older runtime.

Choose `StremCompat-v4.0.2-1080p.ipk` for Full HD and 4K screens, or `StremCompat-v4.0.2-720p.ipk` for smaller screens.
