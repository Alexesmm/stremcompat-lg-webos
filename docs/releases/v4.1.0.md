# StremCompat 4.1.0

## New
- **A cleaner black-and-white look**, as in the big streaming apps: neutral black backgrounds and white focus, with the StremCompat teal kept for progress and the brand.
- **Featured titles on Home:** left alone for a few seconds, the hero passes through the titles of the first catalog row, with dots showing which. Any key brings back the title in focus. Off in the Light look.
- **Best source asks the language too.** The quality menu has a language row on top: OK changes it (any, your language, English) and the choice is kept for next time. It can also be set in **Settings > Playback > Preferred source language**.
- **Simple mode goes straight to the best source** from Play, Continue and episodes. The full list is under **All sources**.
- **Change the source inside the player** from **Settings > Sources**, carrying on from the same place.
- **Chapter marks** on the time bar, when the file has chapters.
- **Title page:** who directed it, the country and the release date.

## Fixed
- **Fill the screen** now crops the picture inside the screen, which LG TVs that ignored the old way also follow.

Choose `StremCompat-v4.1.0-1080p.ipk` for Full HD and 4K screens, or `StremCompat-v4.1.0-720p.ipk` for smaller screens.
