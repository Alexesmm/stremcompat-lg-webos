# StremCompat 1.3.5

## Fixes

- Pressing Up no longer opens the sidebar. It now only moves within the screen, and Left opens the sidebar on every screen, including Search and an empty Home.

## Packages

| Package | Target |
| --- | --- |
| `StremCompat-webOS4-UM4-armv7-graphics-1920x1080-1.2.33.ipk` | webOS 4.x, 1920x1080 application graphics |
| `StremCompat-webOS4-UM4-armv7-graphics-1280x720-1.2.33.ipk` | webOS 4.x, 720p/HD application graphics, including 1366x768 panels |
| `StremCompat-webOS3-UJ3-armv7-graphics-1920x1080-1.0.30.ipk` | webOS 3.x, 1920x1080 application graphics |
| `StremCompat-webOS3-UJ3-armv7-graphics-1280x720-1.0.30.ipk` | webOS 3.x, 720p/HD application graphics, including 1366x768 panels |

Install the matching IPK through LG Developer Mode and webOS Dev Manager. Root access is not required. If you are updating from 1.3.2 or older and the app stays on the loading screen, unplug the television for 30 seconds once.
