# StremCompat 3.0.2

The 720p package is back, for screens smaller than Full HD.

## Which package to use

- **`StremCompat-v3.0.2-1080p.ipk`:** sharper, for Full HD and 4K screens.
- **`StremCompat-v3.0.2-720p.ipk`:** for smaller screens such as 1366x768, where the 1080p interface would be cut off.

The video looks the same in both. On the Homebrew Channel:

- 1080p: `https://alexesmm.github.io/stremcompat-lg-webos/apps.json`
- 720p: `https://alexesmm.github.io/stremcompat-lg-webos/720/apps.json`

Add only one of them. If you installed from the first address and your screen is cut off, remove it and add the second.
