# StremCompat 1.1.0

This release candidate modernizes the television interface while preserving the separate memory and graphics budgets required by webOS 3.x and 4.x devices.

## Highlights

- Fixed icon-only sidebar with predictable Back and directional-pad navigation.
- Independent Discover grid with type, addon catalog and genre filters.
- Incremental Discover pagination using catalogs declared by addons synchronized with the Stremio account.
- Profile-specific Discover limits: 80 items on UM4 and 40 on UJ3.
- Search metadata previews and improved series episode presentation.
- Reduced work during fast navigation through delayed metadata/backdrop updates and stale-request protection.
- Improved player controls, current audio/subtitle indication, Magic Remote clicks and next-episode behavior.
- English first-run interface with Brazilian Portuguese available before and after login.
