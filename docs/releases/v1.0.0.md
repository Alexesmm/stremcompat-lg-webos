# StremCompat for LG webOS 1.0.0

This is the first StremCompat release containing separate compatibility ports confirmed on physical LG televisions.

## Choose the correct package

| Download | Use it for | Confirmed device | Application shown on TV |
|---|---|---|---|
| `StremCompat-webOS4-UM4-armv7-1.2.2.ipk` | ARMv7 televisions running webOS 4.x and Chromium 53 | LG 50UM7500PSB, firmware 05.40.97 | Stremio |
| `StremCompat-webOS3-UJ3-armv7-1.0.1.ipk` | ARMv7 televisions running webOS 3.x and Chromium 38 | LG 49UJ6565-SB, webOS 3.9.3-6280413 (`dreadlocks2-dudhwa`) | Stremio UJ3 |

Do not install both packages merely to discover which one works. Check the webOS TV version in the television information screen and select the matching generation.

## Expected compatibility

- The webOS 3 package is expected to work on similar 2016-2017 UJ, LJ and SJ televisions only when they use a 32-bit ARMv7 processor and provide `/lib/ld-linux.so.3`.
- The webOS 4 package is expected to work on similar 2018-2019 ARMv7 televisions with the same loader.
- A model family alone is not proof of processor compatibility. Only the two televisions listed in the table are currently confirmed.
- ARM64-only televisions, x86 devices and webOS 1.x/2.x are not supported by these packages.
- Televisions running webOS 5 or newer should normally use the official Stremio application.

## Install with webOS Dev Manager

1. Install LG's Developer Mode application from the LG Content Store.
2. Open it, sign in with an LG developer account and enable Developer Mode.
3. Enable Key Server in the Developer Mode application.
4. Open webOS Dev Manager on the computer and add the television using its local IP address.
5. Complete the key/passphrase connection requested by webOS Dev Manager.
6. Download only the IPK matching the television generation.
7. Use the Install button in webOS Dev Manager and select that IPK.
8. Open `Stremio` on UM4/webOS 4 or `Stremio UJ3` on UJ3/webOS 3.

A power cycle is not normally required. If storage is limited, uninstall obsolete test editions before installing. Each compressed IPK is approximately 46 MiB and occupies approximately 92 MiB after installation.

Developer Mode installations are removed when the Developer Mode timer expires. Renew the timer before it reaches zero.

## webOS 3 adaptation

The UJ3 package uses Chromium 38-safe ES5 JavaScript, synchronous startup diagnostics, guarded remote input, reduced catalog and image memory limits, an interface embedded in the local server, and Node.js 18 bridges for Stremio account, addon, TLS and playback traffic. These changes replace the superseded UJ3 0.9.x experiments.

## Important limits

Addon availability and source metadata are external. Playback remains limited by the television's codecs, bitrate, memory, MSE and HLS implementation. Prefer moderate direct or debrid H.264/AAC or television-supported HEVC sources when diagnosing playback.

See the repository README for architecture, profile adaptation, build verification and troubleshooting details.
