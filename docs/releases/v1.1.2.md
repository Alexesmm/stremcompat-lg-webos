# StremCompat 1.1.2

This patch release improves navigation for long-running series while preserving the lightweight runtime designed for older LG televisions.

## Highlights

- Adds continuous episode numbering across regular seasons while retaining the original season and episode identifiers used by addons.
- Adds 50-episode ranges for navigating very long series without rendering every episode at once.
- Adds an in-app episode keypad that works with directional controls, number keys and the LG Magic Remote.
- Adds direct navigation to an overall episode number without relying on browser dialogs unsupported by legacy webOS.
- Improves episode artwork fallback and enriches missing episode details when a compatible installed metadata addon supplies them.
- Keeps compatibility with the legacy Chromium 38 and Chromium 53 targets.
