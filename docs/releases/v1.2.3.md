# StremCompat 1.2.3

This patch release fixes a network issue that could stop the app from loading anything, and improves compatibility with addons that use personal links.

## Fixes

- **The login QR code, email login and catalogs no longer fail on networks with broken IPv6.** Some routers hand out IPv6 without a working IPv6 route to the internet. Browsers and most apps fall back to IPv4, but the app's local service tried the IPv6 address first and gave up, so nothing loaded on any version while Stremio on a phone and other TV apps kept working. The local service and the streaming server now try IPv4 first.
- Addons installed with a personal link that carries a key after `manifest.json` (for example `.../manifest.json?token=...`) now receive that key on every request, as in the official Stremio apps. Before, only addons configured in the link path, such as Torrentio, worked.

## If the app does not load on an older version

Turn IPv6 off on the television (Settings > Network > Wi-Fi or Wired connection > Advanced settings > IPv6) or on the router, or update to this version.
