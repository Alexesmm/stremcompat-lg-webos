# StremCompat 1.2.3

## Fixes

- Fixed the login QR code, email login and catalogs failing to load on networks that hand out IPv6 without a working IPv6 connection. The app's local service and streaming server now try IPv4 first.
- Fixed addons installed with a personal link that carries a key after `manifest.json` (for example `.../manifest.json?token=...`): the key is now sent with every catalog, metadata and stream request, as in the official Stremio apps.

## Other changes

- README troubleshooting now covers the IPv6 issue and how to check that the app's local service is running.
- Added an optional Buy me a coffee link to support development.
