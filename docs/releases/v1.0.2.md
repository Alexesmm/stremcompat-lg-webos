# StremCompat for LG webOS 1.0.2

This release improves the first-run and login experience while retaining separate packages for webOS 3.x and 4.x in both supported application graphics modes. English is now the reliable default and fallback interface language. Portuguese (Brazil) can be selected from the login screen or later under Settings, and the choice is saved locally on the television without changing account, audio or subtitle preferences.

The unauthenticated screen now hides navigation and background branding until login is complete. The pre-interface startup screen also uses English so the language is consistent from the moment the application opens.

Root access and Homebrew Channel are not required. Install the selected IPK with LG Developer Mode and webOS Dev Manager.

## Choose the correct package

First match the webOS generation, then match the graphics mode.

| Download | Use it for | Validation status | Application shown on TV |
|---|---|---|---|
| `StremCompat-webOS4-UM4-armv7-graphics-1920x1080-1.2.4.ipk` | ARMv7 televisions running webOS 4.x and using 1920x1080 app graphics | Physically confirmed on LG 50UM7500PSB, firmware 05.40.97 | Stremio |
| `StremCompat-webOS4-UM4-armv7-graphics-1280x720-1.2.4.ipk` | webOS 4.x ARMv7 televisions with 720p/HD app graphics, including physical 1280x720 and 1366x768 panels | Layout locally validated; physical-TV reports requested | Stremio HD |
| `StremCompat-webOS3-UJ3-armv7-graphics-1920x1080-1.0.3.ipk` | ARMv7 televisions running webOS 3.x and using 1920x1080 app graphics | Physically confirmed on LG 49UJ6565-SB, webOS 3.9.3-6280413 | Stremio UJ3 |
| `StremCompat-webOS3-UJ3-armv7-graphics-1280x720-1.0.3.ipk` | webOS 3.x ARMv7 televisions with 720p/HD app graphics, including physical 1280x720 and 1366x768 panels | Layout locally validated; physical-TV reports requested | Stremio UJ3 HD |

- Use a `graphics-1920x1080` package if the interface already fills the screen correctly.
- Use a `graphics-1280x720` package for 720p/HD televisions, including physical 1280x720 and 1366x768 panels, or if the 1920 package appears only in the upper-left portion of the screen.
- On a physical 1366x768 panel, webOS scales the 1280x720 application surface to the panel. LG web applications do not declare 1366x768 directly as their graphics resolution.
- The selected graphics mode affects the interface surface, not the maximum native video playback resolution.

## What changed

- Added a persistent interface-language selector to the login screen and Settings.
- Made English the first-run and invalid-value fallback language, with Portuguese (Brazil) available as an explicit choice.
- Kept the interface-language preference local and independent from Stremio account, audio and subtitle preferences.
- Hid the main navigation and background logo before authentication for a cleaner login experience.
- Localized static, catalog, detail, source, settings and authentication interface text.
- Updated the startup bootstrap to English and synchronized all package/runtime versions.
- Added automated language fallback, persistence, logout retention, remote-navigation and login-layout checks.

## Testing and feedback

All four packages pass source, runtime, manifest, final-IPK and browser-layout validation at 1920x1080 and 1280x720. The webOS 3.x path was also opened in an official Chromium 38.0.2125.0 snapshot: startup, English fallback, Portuguese selection and persistence, remote input, stored-account login and Home navigation all passed without browser exceptions.

The 1280x720 editions still need reports from physical televisions before individual models can be marked confirmed. Use [GitHub Discussions](https://github.com/Alexesmm/stremcompat-lg-webos/discussions) for installation questions, television compatibility reports and general feedback. Use [GitHub Issues](https://github.com/Alexesmm/stremcompat-lg-webos/issues) for reproducible defects.

When reporting a result, include the complete TV model, webOS and firmware versions, exact IPK filename, available storage, what worked, and a photo or complete error code when something failed. Never publish passwords, tokens or an active pairing QR code.

## Important limits

These packages require a 32-bit ARMv7 television with the compatible webOS loader. Playback remains limited by the codecs, audio formats, bitrate, memory, MSE and HLS support available in the TV firmware. See the repository README for full compatibility guidance, installation steps and troubleshooting.
