# StremCompat 1.2.2

This patch release answers feedback from an LG OLED55E8 (webOS 4.4) report and keeps the interface steady whatever the length of titles and descriptions.

## Fixes

- Episodes watched on any Stremio app now show their watched mark. The watched state stored by Stremio is decoded with the same rules as the official apps.
- Films count as watched when Stremio marks them watched, including films finished on another device.
- Continue Watching appears on Home only and is no longer repeated in Library.

## Steadier layout

- The episode list no longer moves up and down with the length of each episode description.
- On Home, the logo or title of the focused item sits in a fixed box, so the details below it stay in place while moving between titles.
- Title pages reserve the logo space at once instead of moving the buttons and episodes when the logo arrives.
- Long subtitles in the source list and long catalog names stay on one line.
