# StremCompat 3.0.1

Fixes from testing and a code review of 3.0.0.

## What changed

- **Best source:** from the title page it goes straight to the film without showing the list. There is also a button in the source list, which starts the best source of the episode you opened. It asks for the quality each time, unless you set one in Settings.
- **Pausing:** a stream that goes through the app's proxy no longer loses its connection during a pause.
- **Slow torrents:** the app waits longer for a torrent to find peers, and a failure message no longer stays over a film that starts after all.
- **Trying another source:** the source that failed is no longer offered again when its name has more than one line.
- **Best source choice:** it follows your preferred language and quality, prefers a known quality over an unknown one, and is the source marked as the likely best choice. It no longer measures the connection, so it starts right away.
- **Cleaner source list:** file names take one line, or two on the focused source, and codecs only show when they are a compatibility warning.
- **Language:** on first use the app opens in the TV's language, if it is one of the seven available. Your choice in Settings always wins.
- **Subtitles inside the file:**
  - a track that cannot be read says so once;
  - going back before where reading began brings the lines back;
  - stored subtitles belong to one release of a torrent;
  - a file that could not be read is no longer remembered as having no subtitles.
- **Languages:** automatic audio and subtitle choice recognizes more language codes.
- **Source list:** pressing Down while it is still empty no longer loses the focus.
