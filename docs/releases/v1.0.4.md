# StremCompat for LG webOS 1.0.4

This update improves native player controls and Magic Remote support while keeping the conservative memory and rendering limits used on older ARMv7 televisions. It also strengthens recovery after QuickStart+ resume or interruption of the local playback bridge.

Root access and Homebrew Channel are not required. Install the selected IPK with LG Developer Mode and webOS Dev Manager.

## What changed

- Fixed Play/Pause operation from the on-screen player button and compatible remote media keys.
- Player controls now show the currently selected subtitle and audio track.
- Corrected directional navigation between the progress bar and the lower control row.
- Added conservative Magic Remote pointer and click support in the player and main interface.
- Added a guarded native-media fallback when the webOS player reports transient playback errors.
- Added lightweight bridge health checks and recovery after visibility changes and QuickStart+ resume.
- Preserved the catalog navigation fixes and height-aware 720p/1366x768 layout from version 1.0.3.

## Validation

All four generation-and-resolution profiles pass the frontend, runtime, Chromium 38 compatibility, staged-package and IPK verification suites. The 1920x1080 webOS 4 build was also tested successfully on a physical LG 50UM7500PSB after an in-place Developer Mode update and cold restart.

Developer Mode updates can temporarily leave the previous local runtime resident. If an in-place test update asks for reinstallation, first close the app and restart the television. This is a sideload testing limitation and is not intended to be part of the normal user experience.

## Important limits

These packages require a compatible 32-bit ARMv7 webOS loader. Addon availability depends on each external service, and video playback remains limited by the codecs, bitrate, memory and media APIs available in the television firmware.
