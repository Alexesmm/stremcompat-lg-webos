# Confirmed legacy LG webOS builds

This release contains the two profiles confirmed on physical LG televisions.

## Included packages

### Stremio UM4 1.2.2

- File: `io.strem.tv_1.2.2_all.ipk`
- App ID: `io.strem.tv`
- Confirmed on LG 50UM7500PSB, firmware 05.40.97
- Intended platform: ARMv7 televisions running webOS 4.x and Chromium 53

### Stremio UJ3 Native 1.0.1

- File: `io.strem.tv.uj3native_1.0.1_all.ipk`
- App ID: `io.strem.tv.uj3native`
- Confirmed on LG 49UJ6565-SB, webOS 3.9.3-6280413 (`dreadlocks2-dudhwa`)
- Intended platform: ARMv7 televisions running webOS 3.x and Chromium 38

The UJ3 edition uses an embedded legacy interface, a separate service and local port, reduced memory limits, Chromium 38-safe JavaScript, and local Node.js bridges for Stremio account, addon and playback traffic.

## Installation

Install only the IPK matching the television's webOS generation through webOS Dev Manager. The UJ3 application appears on the television as `Stremio UJ3`.

These packages require a 32-bit ARMv7 television with `/lib/ld-linux.so.3`. They are not intended for ARM64-only devices or webOS 1.x/2.x. Newer televisions should normally use the official Stremio application.

See the repository README for architecture, adaptation instructions, limitations and troubleshooting.
