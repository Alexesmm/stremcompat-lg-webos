# StremCompat for LG webOS 1.0.1

This release adds separate 1920x1080 and 1280x720 application graphics packages for both supported legacy webOS generations. It fixes the case where the interface occupies only the upper-left portion of a television whose web applications use the 1280x720 graphics mode.

Root access and Homebrew Channel are not required. Install the selected IPK with LG Developer Mode and webOS Dev Manager.

## Choose the correct package

First match the webOS generation, then match the graphics mode.

| Download | Use it for | Validation status | Application shown on TV |
|---|---|---|---|
| `StremCompat-webOS4-UM4-armv7-graphics-1920x1080-1.2.3.ipk` | ARMv7 televisions running webOS 4.x and using 1920x1080 app graphics | Physically confirmed on LG 50UM7500PSB, firmware 05.40.97 | Stremio |
| `StremCompat-webOS4-UM4-armv7-graphics-1280x720-1.2.3.ipk` | ARMv7 televisions running webOS 4.x and using 1280x720 app graphics | Layout locally validated; physical-TV reports requested | Stremio HD |
| `StremCompat-webOS3-UJ3-armv7-graphics-1920x1080-1.0.2.ipk` | ARMv7 televisions running webOS 3.x and using 1920x1080 app graphics | Physically confirmed on LG 49UJ6565-SB, webOS 3.9.3-6280413 | Stremio UJ3 |
| `StremCompat-webOS3-UJ3-armv7-graphics-1280x720-1.0.2.ipk` | ARMv7 televisions running webOS 3.x and using 1280x720 app graphics | Layout locally validated; physical-TV reports requested | Stremio UJ3 HD |

- Use a `graphics-1920x1080` package if the existing interface already fills the screen correctly.
- Use a `graphics-1280x720` package if the 1920 package appears only in the upper-left portion of the screen.
- A television with a physical 1366x768 panel must use the `graphics-1280x720` package. LG web applications do not declare 1366x768 as their graphics resolution.
- The selected graphics mode affects the interface surface, not the maximum native video playback resolution.

## What changed

- Added independent 1280x720 packages for webOS 3.x and webOS 4.x.
- Kept the confirmed 1920x1080 packages as separate downloads.
- Made card-row navigation use the actual viewport width instead of a fixed 1920-pixel calculation.
- Added manifest, staged-build and final-IPK resolution checks.
- Added automated browser layout checks and screenshots for all four generation-and-resolution combinations.
- Gave each package its own application ID, service ID and local port to prevent stale-process collisions during testing.

## Testing and feedback

All four packages pass source, runtime, manifest, IPK and local browser-layout validation. The 1280x720 editions still need reports from physical televisions before individual models can be marked confirmed.

Use [GitHub Discussions](https://github.com/Alexesmm/stremcompat-lg-webos/discussions) for installation questions, television compatibility reports and general feedback. Use [GitHub Issues](https://github.com/Alexesmm/stremcompat-lg-webos/issues) for reproducible defects.

When reporting a result, include the complete TV model, webOS and firmware versions, exact IPK filename, available storage, what worked, and a photo or complete error code when something failed. Never publish passwords, tokens or an active pairing QR code.

## Important limits

These packages require a 32-bit ARMv7 television with the compatible webOS loader. Playback remains limited by the codecs, audio formats, bitrate, memory, MSE and HLS support available in the TV firmware. See the repository README for full compatibility guidance, installation steps and troubleshooting.
