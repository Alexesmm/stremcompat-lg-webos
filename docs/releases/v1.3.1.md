# StremCompat 1.3.1

## New

- External subtitles now come from the subtitle addons installed on your Stremio account, not only from the public OpenSubtitles addon. They are asked with the video's file name and, for torrents, its hash, as the official apps do, so subtitles synced to that exact file come first. The subtitle menu shows which addon each subtitle came from.
- Sources marked "Multi Subs" now show their flags as subtitle languages (for example `LEG EN · PT-BR +4`) instead of audio languages. The language filter still lists them for each of those languages.

## Fixes

- Embedded subtitle tracks are read much faster: only the file's header is checked, without analysing the video. Torrents with many attached fonts (common in anime) get more time before giving up.
- When the embedded track list cannot be read yet, the menu now says the file is still loading and offers **Try again**. Before, the error stayed until the video was reopened.
- The paused screen and the subtitle menu now share one read of the file instead of two.
- The player controls no longer hide while the subtitle list, a chosen subtitle or a new audio track is still loading.
- Subtitles with accents saved in older encodings (Windows-1252), ASS/SSA, WebVTT and compressed subtitle files now display correctly.
- The Local files addon is no longer asked for catalogs, metadata and sources, since the TV has no local video library.
- Settings > Diagnostics now shows why an addon did not answer (time out, HTTP 429, HTTP 503…).
