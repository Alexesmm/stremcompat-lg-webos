# StremCompat 1.1.1

This patch release improves navigation resilience and visual presentation while preserving the lightweight runtime designed for older LG televisions.

## Highlights

- Adds a clear Watch action to movie details so playback sources are immediately discoverable.
- Prevents delayed artwork requests from replacing the poster for the currently selected title.
- Adds a safe Reload StremCompat action that preserves the account, addons, library, progress and preferences.
- Makes Magic Remote pointer navigation more controlled with lightweight hover debouncing.
- Exposes additional catalog types declared by installed addons, including Anime, in Discover.
- Refines the cinematic split-backdrop layout while keeping only one backdrop texture active.
- Adds a cleaner, minimal first-start loading screen consistent with the rest of the interface.
- Keeps compatibility with the legacy Chromium 38 and Chromium 53 targets.
