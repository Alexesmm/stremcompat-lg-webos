# StremCompat 4.2.1

## Better
- **Audio and subtitles told apart in the source list.** The language of a source is read from more clues:
  - Torrentio's flags count as audio only with Multi Audio or Dual Audio. With Multi Subs, or when a release lists three or more flags without saying so (streaming rips with many subtitle tracks), only the first is audio and the rest are subtitles.
  - Subtitle lists in names are read: "SUB ITA ENG", "Sub (rus eng)", "Eng Subs", "Multisub", "Legendado", "VOSTFR", "ESub".
  - "Dublado" means Portuguese audio, and "Legendado" with a 🇧🇷 flag means Portuguese subtitles.
- **The language filter** opens with **By audio (dubbed)** and **By embedded subtitles**. **Remove the filter** appears only while a filter is on, and the button says **Filter by language** when none is.

Everything new in 4.2 is in the [4.2.0 notes](https://github.com/Alexesmm/stremcompat-lg-webos/blob/main/docs/releases/v4.2.0.md).

Choose `StremCompat-v4.2.1-1080p.ipk` for Full HD and 4K screens, or `StremCompat-v4.2.1-720p.ipk` for smaller screens.
