# StremCompat for LG webOS 1.0.3

This patch fixes catalog navigation reported on a physical 1366x768 television and improves Home catalog completeness on every supported graphics mode. The underlying focus defect was shared by the 1280x720 and 1920x1080 builds, although it was more visible on the shorter 720p application surface.

Root access and Homebrew Channel are not required. Install the selected IPK with LG Developer Mode and webOS Dev Manager.

## What changed

- Remote Up and Down now move only between populated, visible catalog rows.
- A failed, empty or unavailable addon catalog no longer captures focus or leaves the Home board apparently fixed.
- Focus automatically settles on the first successful row even when the first addon request fails.
- Home now keeps up to 24 addon catalog rows on UM4 and 16 on the lower-memory UJ3 profile instead of silently stopping at eight.
- The 1280x720 layout now uses a height-aware hero and smaller catalog cards, keeping the focused card fully inside the viewport on 720p and physical 1366x768 panels.
- Horizontal movement measures the rendered card spacing instead of assuming 1080p card dimensions.

Catalogs whose manifest declares a required extra parameter are still intentionally excluded from Home, matching the Stremio addon protocol. Catalog item counts remain profile-limited to protect the small memory budget of these televisions.

## Validation

All four generation-and-resolution profiles were tested with a simulated account containing 14 catalog rows and two interleaved failing endpoints. The 12 successful rows remained visible, Down skipped each failed row, the board moved, and the focused card stayed within both 1920x1080 and 1280x720 viewports. The same failure-isolation and scrolling scenario passed in Chromium 38.0.2125.0.

## Important limits

These packages require a compatible 32-bit ARMv7 webOS loader. Addon availability still depends on each external service, and video playback remains limited by the codecs, bitrate, memory and media APIs available in the television firmware.
