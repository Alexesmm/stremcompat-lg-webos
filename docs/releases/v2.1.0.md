# StremCompat 2.1.0

The next episode now starts directly from the player, and torrents can use a streaming server on another computer.

## Before you install

**Coming from a version 1.x app:** this is installed as a new app. Remove the old one first (`Stremio`, `Stremio HD`, `Stremio UJ3` or `Stremio UJ3 HD`), then install the package for your TV. You may need to sign in again. The first torrent downloads the streaming server directly from Stremio, so it takes longer once.

## Changes

- **Next episode:** starts straight from the player instead of going back to the title page. It keeps the same release when the addon marks one, or the same addon, quality and audio language. When no source matches, the list opens so the language does not change without you noticing. This also works between seasons.
- **Subtitles:** playback waits up to ten seconds for a subtitle you choose in the menu, then continues.
- **Do not save history:** a new option in **Settings > History**. While it is on, no progress, watched state, played source or search is saved on the TV or sent to your account. Addons and streaming servers still receive their normal requests, and positions saved earlier are still offered.
- **Streaming server address:** **Settings > Streaming server > Address** sends torrents to a server on another computer. The address is saved only after a server answers there, and **Use this TV** goes back.
- **Recommended source:** no longer goes to a source with a compatibility note when a source without one is available.
