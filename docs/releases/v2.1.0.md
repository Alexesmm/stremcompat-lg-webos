# StremCompat 2.1.0

This is the first release since 1.3.5, and it includes everything from 2.0.0, which was not published separately. The app has a new identity, no longer ships Stremio's streaming server, and gains a more direct way to binge a series.

## Before you install

**Coming from 1.x, this installs as a new app.** Remove the old one first (`Stremio`, `Stremio HD`, `Stremio UJ3` or `Stremio UJ3 HD`), then install the package for your TV.

- You may need to sign in again. Your library, progress and addons are on your Stremio account.
- The first time the app opens, the TV downloads the streaming server once, in the background. A torrent opened before it finishes waits for it. Debrid and direct links do not use it, so they are not affected, even if the download fails.
- The new app does not replace the old one by itself, because the app ID changed. From now on, updates install over this app as usual.

## A new identity

**What changed**

- The app is now called StremCompat on the TV (`StremCompat`, `StremCompat HD`, `StremCompat UJ3`, `StremCompat UJ3 HD`), with its own logo and app IDs.
- The sign-in screen says that this is an unofficial client, not affiliated with or endorsed by Stremio or LG.
- The purple interface is now teal and cyan, to match the new logo.

**Why:** the name and logo belong to Stremio, and an unofficial project should not look like their app. It works exactly as before with your Stremio account and addons.

## Stremio's streaming server is no longer in the package

**What changed**

- The first time the app opens, the TV downloads the streaming server directly from Stremio in the background, checks its SHA-256 and keeps it for later. A file that does not match is never run.
- If the download fails, the app says so when you open a torrent, and **Settings > Diagnostics** shows the reason.
- The packages now include the license texts of their third-party components.

**Why:** that server is Stremio's closed-source software, so this project should not be redistributing it. This lowers the licensing risk but is not an approval from Stremio, and the project's remaining licensing questions are listed in `NOTICE.md`.

## Next episode

**What changed**

- The next episode starts straight from the player, also across seasons, instead of going back to the title page.
- It keeps the same release when the addon marks one. Otherwise it looks for the same addon, quality and audio language.
- When no source matches, the source list opens instead of changing the language without you noticing.

**Why:** a dubbed series could continue with a source in another language, and watching several episodes meant going through the title page each time.

## Subtitles

**What changed:** playback waits up to ten seconds for a subtitle you choose in the menu, then continues even if it is still loading.

**Why:** the subtitle used to appear some time after you chose it, so you could miss the lines in between.

## Do not save history

**What changed:** a new option in **Settings > History**. While it is on, no progress, watched state, played source or search is saved on the TV or sent to your account. Positions saved earlier are still offered.

**Why:** so you can watch something without it reaching Continue Watching or your account on other devices. It is not an anonymous mode: addons and streaming servers still receive their normal requests.

## Streaming server address

**What changed:** **Settings > Streaming server > Address** sends torrents to a server on another computer. The address is saved only after a server answers there, and **Use this TV** goes back. Nothing is downloaded to the TV while another server is set.

**Why:** it was requested by the community, and it can help on TVs with very little free memory. So far it has only been tested against a simulated server, so reports from real setups are welcome.

## Smaller changes

- **Recommended source:** no longer goes to a source with a compatibility note when one without a note is available.
- **Sign-in screen:** says which account to use and where to create one, for people who are new to Stremio.
- **README:** new screenshots and a first-use guide.
