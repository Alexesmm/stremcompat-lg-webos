# StremCompat 2.0.0

StremCompat now has its own name, logo and app identity on the TV, and the package no longer includes Stremio's streaming server.

## Before you install

**This version is installed as a new app.** Remove the old one first (`Stremio`, `Stremio HD`, `Stremio UJ3` or `Stremio UJ3 HD`), then install the package for your TV. You may need to sign in again. Your library, watched history and addons are stored on your Stremio account.

## Changes

- The app is now called StremCompat on the TV, with a new logo and its own app ID. It is an unofficial client and is not affiliated with or endorsed by Stremio or LG.
- Stremio's streaming server is no longer inside the package. The first time it is needed, the TV downloads it directly from Stremio, checks it and keeps it for later. Torrents need this download; debrid and direct links do not.
- If that download fails, the app says so when you open a torrent, and **Settings > Diagnostics** shows the reason.
- The package now includes the license texts of its third-party components.
