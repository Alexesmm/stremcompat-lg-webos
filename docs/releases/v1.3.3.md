# StremCompat 1.3.3

## Fixes

- Fixed the app staying on the loading screen and ending with `RUNTIME_START_TIMEOUT` after an update. The local service of the previously installed version kept running in the background (even after removing the app) and held its port, so the new version could not start until the television was unplugged. The new version now tries to stop the old service by itself and start in its place.
- If the old service cannot be stopped, the loading screen now says so after about 30 seconds and asks to unplug the television, instead of waiting 90 seconds for `RUNTIME_START_TIMEOUT`. The code on that screen (for example `STALE_SERVICE 1.2.25`) tells which version was still running.
