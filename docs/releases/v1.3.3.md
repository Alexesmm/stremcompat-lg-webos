# StremCompat 1.3.3

## Fixes

- Fixed the app staying on the loading screen and ending with `RUNTIME_START_TIMEOUT` after an update. The local service of the previously installed version kept running in the background (even after removing the app) and held its port, so the new version could not start until the television was unplugged. The new version now stops the old service by itself and starts in its place.

## Packages

| Package | Target |
| --- | --- |
| `StremCompat-webOS4-UM4-armv7-graphics-1920x1080-1.2.26.ipk` | webOS 4.x, 1920x1080 application graphics |
| `StremCompat-webOS4-UM4-armv7-graphics-1280x720-1.2.26.ipk` | webOS 4.x, 720p/HD application graphics, including 1366x768 panels |
| `StremCompat-webOS3-UJ3-armv7-graphics-1920x1080-1.0.23.ipk` | webOS 3.x, 1920x1080 application graphics |
| `StremCompat-webOS3-UJ3-armv7-graphics-1280x720-1.0.23.ipk` | webOS 3.x, 720p/HD application graphics, including 1366x768 panels |

Install the matching IPK through LG Developer Mode and webOS Dev Manager. Root access is not required. If you are updating from 1.3.2 or older and the app still stays on the loading screen, unplug the television for 30 seconds once; later updates do not need it.
