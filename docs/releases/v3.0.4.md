# StremCompat 3.0.4

- **720p package:** Settings and the side menus now have the right size, instead of the larger 1080p sizes.
- **Version number:** the 3.0.3 packages reported 3.0.2 inside, so the Homebrew Channel did not offer them. This version fixes that.

Choose `StremCompat-v3.0.4-1080p.ipk` for Full HD and 4K screens, or `StremCompat-v3.0.4-720p.ipk` for smaller screens.
