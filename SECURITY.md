# Security policy

## Supported versions

Security fixes are evaluated for the latest published StremCompat release and its four current UJ3/UM4 graphics packages. Historical development profiles and superseded releases are not actively maintained.

## Reporting a vulnerability

Do not open a public Issue or Discussion for a suspected vulnerability, exposed credential or authentication bypass.

Use GitHub's private **Report a vulnerability** option in the repository Security tab when it is available. If that option is unavailable, contact the maintainer privately through the contact options on the [maintainer's GitHub profile](https://github.com/Alexesmm). Include the affected release, television profile, reproduction steps, impact and any proposed mitigation.

Allow reasonable time for investigation before publicly disclosing the report. You should receive an initial acknowledgement when the report is reviewed, followed by a decision about whether it is accepted, needs more information or does not affect StremCompat.

## Sensitive information

Never include any of the following in a public report, screenshot or log:

- Stremio passwords or authentication tokens.
- Cookies or authorization headers.
- Active mobile-pairing QR codes or pairing codes.
- LG Developer Mode credentials or private keys.
- Private addon credentials or service URLs containing secrets.

Ordinary installation failures, playback incompatibilities and interface defects belong in GitHub Issues or Discussions as described in [CONTRIBUTING.md](CONTRIBUTING.md).
