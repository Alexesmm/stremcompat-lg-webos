# Accessibility

StremCompat is designed primarily for television use with a directional remote control. The interface provides visible focus states, directional navigation, selectable controls and pointer support for LG Magic Remote devices.

The project aims to preserve:

- Complete operation with directional keys, OK and Back.
- A clearly visible focus indicator on interactive elements.
- Readable text and sufficient contrast on dark television backgrounds.
- English and Brazilian Portuguese interface text.
- Stable focus when a catalog, addon or image request fails.
- Layouts suitable for both 1920x1080 and 1280x720 webOS application surfaces.

Known limitations include reliance on the television's legacy Chromium accessibility support, limited screen-reader testing and variations in overscan, scaling and remote-control behavior between LG models.

Report an accessibility barrier through [GitHub Discussions](https://github.com/Alexesmm/stremcompat-lg-webos/discussions) when help or investigation is needed, or use a [GitHub Issue](https://github.com/Alexesmm/stremcompat-lg-webos/issues) when the problem is reproducible and requires a project change. Include the exact television model, webOS version, package filename, navigation method and a description or photograph of the problem. Do not include private account information or active pairing codes.
